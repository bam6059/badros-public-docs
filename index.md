# BadrOS personal workspace

BadrOS is a privately operated personal workspace. Its owner runs the application
on their own computer and accesses it from paired desktop and mobile clients.
This public website contains documentation only. It does not provide access to
the private application, personal files or mailbox.

## Optional Gmail connection

The Gmail integration lets the owner connect their Google account, search and
read selected messages, save selected message text in their local workspace,
and send an email with a specified recipient and message. An optional permission
upgrade enables moving a selected message to Gmail Trash. Google authorization
is required before accessing Gmail; an existing read-and-send connection is not
silently granted the additional permission.

For an optional AI summary, the owner selects message text and sends a question.
The mail destination is the owner's connected ChatGPT account with model
improvement disabled, not whichever provider is selected for ordinary chat.
There is no automatic fallback to DeepSeek for recognized Gmail copies. This
does not upload the whole mailbox or email attachments. The
[privacy policy](privacy.html) explains the processing conditions and limits.

BadrOS is a personal application, not a public email service or a Google product.
Gmail API access does not require a paid BadrOS subscription. Separately selected
AI services may charge for their use.
